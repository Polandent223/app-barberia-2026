SAMBRIX 1.0 PRODUCCIÓN — V5

Cierre financiero de citas:
- Finalizar una cita ahora solicita método de pago y monto cobrado.
- Métodos: Efectivo, Pago móvil, Transferencia, Divisa, Tarjeta y Otro.
- Caja y recibo quedan vinculados a la cita, cliente, negocio y sucursal.
- Finalización idempotente: un reintento no duplica venta, caja, puntos ni visitas.
- Numeración de recibos usa el mayor correlativo existente, evitando duplicados tras eliminaciones.
- Recibos muestran método de pago.
- Historial de gasto del cliente prioriza clientId sobre nombre para evitar confundir homónimos.
- Movimientos manuales de caja incorporan businessId y branchId.
- Registros financieros heredados reciben identidad del tenant activo sin mover datos entre negocios.

Validaciones automáticas de esta entrega:
- Sintaxis JavaScript: 0 errores.
- IDs HTML duplicados: 0.
- Recursos locales faltantes: 0.
- Prueba lógica de doble finalización: PASA (1 venta, 1 caja, 1 visita).
- Prueba lógica de aislamiento de dos negocios: PASA.

Nota: para declarar SAMBRIX listo para clientes reales todavía falta ejecutar el smoke test contra el proyecto Firebase desplegado y verificar autenticación/reglas en red real.
